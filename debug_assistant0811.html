1. 匯入 Netlist

EasyEDA: File → Export → Netlist,格式選 Protel(這個工具目前只支援 Protel 格式,不支援 PADS)

2. 上傳原始 SVG(選用)

EasyEDA: File → Export → SVG。上傳後可看到跟你實際畫面一樣的版面,並且精準定位元件。

3. 上傳 3D 預覽(選用)

EasyEDA Pro: PCB → Export → Interactive BOM。這是 EasyEDA 自己的 3D 引擎,直接嵌入分頁顯示。
